If Zaparoo and RomM read the same ROM files (e.g. a shared network folder), set the roms root path above to where Zaparoo sees RomM's library. RomM's own file paths often start with an extra folder name (commonly roms/) that isn't part of that shared structure — use the prefix field to strip it, if a test launch shows it in the wrong place. Launches then use the exact file path instead of guessing by name, falling back to guessing only if that fails. Leave both blank to always guess by name.
